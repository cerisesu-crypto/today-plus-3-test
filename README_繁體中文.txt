TODAY+ 2.0 更新說明

本版包含清宮雅韻風配色、首頁／任務／月曆／統計四個頁面、任務新增編輯刪除與完成、日期、多元分類、優先順序、時段與備註、月曆任務標記、搜尋篩選、每日進度及近七日統計。

資料使用 localStorage 保存在目前裝置／瀏覽器。清除網站資料可能刪除任務紀錄。

分類包含生活、工作、健康、運動、學習、家庭、購物、財務、人際、休閒及其他；優先順序分為高、中、低。\n\n目前尚未加入 Google 登入、雲端同步及背景推播提醒。這些功能需要另外設定服務與權限。

更新方式：將 ZIP 內六個檔案上傳並覆蓋 GitHub 專案根目錄同名檔案。GitHub Pages 部署完成後，重新開啟原本 TODAY+ 網址。
